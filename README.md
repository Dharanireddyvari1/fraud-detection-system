# Fraud Detection System

A machine learning-based fraud detection system with FastAPI backend, LLM integration for reasoning, and real-time streaming capabilities.

## Features

- Real-time fraud detection using ML models
- LLM-powered fraud reasoning and explanation
- FastAPI REST API
- Docker containerization
- Streaming data support
- Observability with Langfuse

## Project Structure

```
fraud-detection-system/
├── src/
│   ├── api/           # FastAPI application
│   ├── data/          # Data processing and streaming
│   ├── llm/           # LLM integration
│   ├── models/        # Model training
│   └── observability/ # Monitoring and logging
├── notebooks/         # Jupyter notebooks for EDA
├── data/              # Data storage
├── models/            # Trained models
├── tests/             # Test suite
└── docker-compose.yml # Docker orchestration
```

## Setup

1. Clone the repository
2. Copy `.env.example` to `.env` and configure
3. Install dependencies: `pip install -r requirements.txt`
4. Run with Docker: `docker-compose up`

## API Documentation

Once running, visit `http://localhost:8000/docs` for interactive API docs.
